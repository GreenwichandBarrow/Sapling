## Voice + Content Rules

- Terse. 2-4 lines per section body. No dense paragraphs.
- Forward-looking. Reference what changed since last LIVE touch.
- No em dashes in prose. Em dashes OK only as bullet-list descriptor separators in the niche list.
- No HoldCo / search-fund / fund language.
- No "Questions for {Investor}" section.
- No frontmatter in rendered Doc body.
- No sign-off.
- Guillermo-specific: when he surfaces a diligence-framework or operational tool (e.g., "tools-for-walls", 4/21), capture it as a niche signal AND reference it in the next biweekly brief so he sees the thread continuing.
- Window = since last LIVE conversation, not since last scheduled slot.
