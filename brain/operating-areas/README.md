# Operating Areas

This folder keeps Kay's role and department separation inside the shared Sapling workspace.

Use this structure when work needs to be available from every device:

- iMac
- MacBook
- iPhone through a connected Codex host
- VPS automation

The canonical Codex project remains:

```text
vps:/home/ubuntu/projects/Sapling
```

Do not create device-local Codex projects for ongoing operational work unless the work truly belongs only on that device.

## Filing Rule

Use `brain/operating-areas/...` for role-specific strategy, context, decisions, recurring responsibilities, and handoff notes.

Use the existing shared Sapling folders for cross-functional operational artifacts:

- `brain/context` for current state and snapshots
- `brain/entities` for people and company records
- `brain/trackers` for process trackers
- `brain/calls` for call notes
- `brain/briefs` for meeting and investor briefs
- `brain/traces` for decision traces and agent work records
