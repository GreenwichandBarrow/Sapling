# Greenwich & Barrow Squarespace Visual Redesign Notes

## Direction

Use this as a visual redesign reference for the existing Squarespace site, not a new platform. The intended feel is editorial, restrained, warm, and credible: broader than the prior luxury-only site, but not generic private equity.

## Section Map

1. Header
   - Left wordmark: Greenwich & Barrow
   - Nav: Approach, Criteria, Perspective, Contact
   - Keep background warm off-white with a thin divider.

2. Hero
   - Two-column section.
   - Left: large serif headline.
   - Right: tall editorial image, black-and-white treatment if possible.
   - Add a small dark-green text block over or below the image.

3. Trust Statement
   - Full-width dark green band.
   - Oversized serif statement.
   - No card.

4. Approach
   - White band.
   - Left heading, right body copy.
   - Emphasize thesis-informed but opportunistic.

5. Criteria
   - Three equal columns with thin borders.
   - Critical service, Client trust, Local reputation.

6. Areas of Interest
   - Soft green band.
   - Use a simple list, not logo tiles or cards.

7. Perspective
   - Editorial article list.
   - Can link to existing Squarespace blog/notes pages later.

8. Contact
   - Dark section.
   - Email-only CTA.

## Visual Tokens

- Background: #f7f5ef
- Text: #161a17
- Dark green: #193b2c
- Muted green: #60715e
- Accent red/brown: #7e2f2f
- Clay accent: #b56b45
- Rules: #d9d5ca

## Type Direction

- Use Avenir or Avenir Next as the primary font family.
- Avoid serif-led typography for the redesign.

- Use the current site font: PT Serif.
- Keep navigation and small labels uppercase with generous letter spacing.
- Use the Brand Kit logo assets from `MANAGER DOCUMENTS / G&B BRAND KIT / G&B LOGOS`, not a typed wordmark.
- Use the Brand Kit website images from `G&B WEBSITE IMAGES`; this mockup uses HANDS, BOAT, BUDS, and florals.
- Avoid script, overly feminine fashion typography, and heavy PE-style navy.

## Squarespace Build Guidance

- Start from the current Squarespace site and rebuild the homepage sections in this order.
- Use full-bleed sections with constrained inner content.
- Avoid card-heavy layouts.
- Keep the founder/persona mostly off-page unless Kay decides to bring back a light founder note.
- Use custom CSS only for spacing, borders, typography scale, and color polish.
- Replace the prototype image with better photography before launch if possible.
