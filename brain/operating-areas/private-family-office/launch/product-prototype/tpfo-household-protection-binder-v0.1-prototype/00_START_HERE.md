# TPFO Household Protection Binder

Prototype version: 0.1

## What This Is

This is a digital-first starter system for organizing important household documents, protected originals, access points, and review routines.

The word **Binder** is used as part of the academic/library/archive language of The Private Family Office. It does not mean the product is a traditional paper binder.

## What To Do First

1. Read the short field guide.
2. Create the recommended digital folder structure in the cloud or local storage system you already use.
3. Use the workbook to record what exists and where it lives.
4. Identify which originals need protected physical storage.
5. Set review timing for documents that expire, renew, or need periodic review.

## Privacy Standard

This system helps you locate and organize sensitive information. It should not be used to write down passwords, PINs, Social Security numbers, full account numbers, or other sensitive underlying data in an unsecured place.
