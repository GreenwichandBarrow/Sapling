# Naming Convention Guide

A naming convention makes documents findable later. The best naming system is plain, consistent, and boring enough to use every time.

## Recommended Pattern

YYYY-MM-DD - Person or Household - Document Type - Institution or Detail

## Examples

- 2026-01-15 - Household - Homeowners Insurance Declaration - Carrier Name
- 2026-04-10 - Child Name - Passport Renewal Confirmation
- 2025-12-31 - Household - Property Tax Record - Town Name
- 2024-06-01 - Adult Name - Power of Attorney - Attorney Name

## Practical Rules

- Start with the date when the date matters.
- Use full names for people where helpful.
- Use one document type phrase consistently.
- Avoid vague names like scan, final, document, or important.
- If a document is superseded, move the old version to Archive rather than deleting it immediately.
