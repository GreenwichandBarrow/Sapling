Rule: When Kay asks me to prep for a conference she's attending, the deliverable goes in a **Google Doc** inside a **subfolder named after the conference** under the Conferences parent folder in Drive. **Never deliver the prep content in the chat.**

**Why:** Kay needs prep docs mobile-accessible at the event (Drive on phone), not buried in chat scrollback. Per-conference subfolders keep prep organized for retrospective review (what worked / what didn't), align with the conference-engagement skill's pre/post lifecycle, and avoid leaking Kay's strategic intel (acquisition lens, target sub-segments, sourcing intent) into a transcript that lives in `~/.claude/projects/...`.

**How to apply:**
- On a conference-prep request: locate the Conferences parent folder in Drive, create a subfolder with the conference name (or use existing one if Kay's already attended/registered), create a Google Doc titled like `{Conference Name} - Prep` or `{Conference Name} - Talking Points`, write the content there.
- Chat output: ONLY the Drive link to the doc + a 2-3 sentence summary of what's inside (sections covered, headline asks). Never the talking-point list verbatim.
- Same pattern for: post-conference notes, attendee follow-up lists, business-card transcripts. All conference-related artifacts go in the conference's subfolder.
