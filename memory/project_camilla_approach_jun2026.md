**Operating approach for the next few months, from the 2026-06-02 Camilla (TB) call.** Claude green-lit it with refinements; Kay is running with it. NOT yet codified as hard defaults — revisit ~mid/late June before promoting to skill defaults (Claude told Kay he'd codify "once she's run it a week or two").

**The approach:**
1. **Outreach channel order for a target company: LinkedIn → Instagram → email.** Protects sender domain (email last = least bounce risk). Refinements Claude flagged: for a true cold stranger, LinkedIn is the *warm-up* (connect/engage), not an instant pitch (stay inside warm-intro-first per [[feedback-no-cold-outreach-to-strangers]]); **Instagram is situational** — good for luxury / art-world / women-led / consumer-facing owners (fits [[user-kay-women-led-purpose-throughline]]), low-value for B2B industrial owners, so apply by target type; when reaching the email rung, **Apollo-verified addresses only, never constructed** ([[feedback-apollo-only-emails]]); log channel-touched per target to keep channel universes separate ([[feedback-outreach-channel-universes-separate]]).
2. **Focus mostly on conferences + brokers/intermediaries** for the next few months. On-strategy: highest-ROI channel, Kay's relational edge, dovetails with the DealsX/JJ wind-down ([[dealsx-jj-windown-by-summer]]), and is runway-friendly (local conferences mostly free/cheap; intermediaries relationship-driven).
3. **Camilla supports industry evaluation.** She **already knows the buy-box + scorecard** (no rubric needed). Kay forwards **broker listings** to Camilla for her opinion (Kay self-identified as the bottleneck/"blocker") and will **forward all email listings** to Camilla for consideration. Final go/no-go stays with Kay (CEO / Deal-1 owner). Watch-out: don't let "forward everything to Camilla" just move the bottleneck — pair with a return cadence; ideally Camilla sits on top of existing email-intelligence/deal-aggregator classification, not parallel.

**How to apply:** when routing outreach or triaging inbound this summer, follow channel order + the conferences/intermediaries focus, and route broker/email listings to Camilla. Revisit before locking as defaults.
